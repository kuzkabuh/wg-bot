# Changelog

## 0.1.3 — 2025-09-27
### Исправления
- Исправлена генерация клиентского конфигурационного файла: в блок `[Peer]` теперь добавляется `PresharedKey` (если сгенерирован) — конфиг успешно импортируется в мобильный WireGuard, а подключение работает корректно.
- `AllowedIPs` в `.conf` теперь берётся из окружения `WG_ALLOWED_IPS` (по умолчанию `0.0.0.0/0,::/0`), что устраняет проблемы с маршрутами у клиента.
- QR-код для импорта конфигурации стабильно создаётся и импортируется.

### Улучшения
- Доработаны меню пользователя и админа: устранены дубли, лаги и некорректные переходы, список устройств формируется построчно и предсказуемо.
- Добавлены краткие docstring-описания ко всем основным функциям (handlers, services), код унифицирован по стилю.
- Актуализированы `README.md` и `requirements.txt`, добавлены пояснения по установке и правам `sudo` для `wg`/`wg-quick`.

### Прочее
- Обновлена версия до `0.1.3` в файле `VERSION`.
- Мелкие правки в `install/*` и служебных скриптах (флаги, комментарии, единообразие прав доступа).
