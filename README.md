# WireGuard Telegram Bot (wg0)

Бот для управления доступами к WireGuard (`wg0`): триал на 7 дней, месячная подписка (заглушка), тариф "безлимит", выдача `.conf` и QR‑кода, просмотр статуса. База — SQLite.

## Возможности

- Регистрация пользователя (по Telegram ID).
- Триал: 7 дней, 1 устройство.
- Месяц: 30 дней, 1 устройство (оплата — заглушка).
- Безлимит: админ может выдать безлимит (∞ устройств, бессрочно).
- Добавление/удаление peer для wg0 (IPv4/IPv6, автоматическая выдача IP).
- Генерация клиентского `.conf` и QR‑кода.  Конфиг включает строку `PresharedKey`,
  если она была сгенерирована, и использует значение из `WG_ALLOWED_IPS` для
  поля `AllowedIPs`.
- Статистика: когда был онлайн, байты TX/RX, статус handshake.
- Админ‑панель: список пользователей, продление, смена лимитов, выдача безлимита, сброс/удаление peer'ов.

## Требования

- Ubuntu 22.04+ (или совместимая).
- Установленный WireGuard и настроенный интерфейс `wg0`.
- Доступ к `wg`, `wg show`, `wg set`, `wg-quick save` и правам root для конфигурации.
- Python 3.10+ (лучше 3.11).
- Возможность дать боту безпарольный sudo на команды `wg`, `wg-quick` и редактирование `/etc/wireguard/wg0.conf`.

## Установка

См. раздел в конце файла ответа (там все шаги, включая `install/install.sh`, systemd‑юнит и sudoers).

## Быстрый старт

1. Скопируйте `.env.example` → `.env` и заполните `BOT_TOKEN`, `ADMIN_IDS`, `SERVER_PUBLIC_ENDPOINT`, `SERVER_PUBLIC_PORT`.
2. Создайте venv и установите зависимости: `pip install -r requirements.txt`.
3. Запустите: `python bot.py`.
4. Для продакшена используйте systemd‑юнит `install/wg-bot.service`.

## Структура БД (SQLite)

- `users` — пользователи
- `peers` — устройства (peer) пользователей
- `events` — лог событий

Создается автоматически при первом запуске.

## Важно про права

Боту нужны права на выполнение:

- `wg`, `wg show`, `wg set`, `wg-quick save`
- Чтение/запись `/etc/wireguard/wg0.conf`

См. файл `install/sudoers.d.wg-bot`.
